# mini_projects
A simple Hospital Management System built in C++ while learning Object-Oriented Programming. It manages ward and patient data using classes like `ward` and `generalward`, and demonstrates core OOP concepts.

## Features
- Admit patients through ward classes
- Store and display ward/patient info

## OOP Concepts Used
- Inheritance (`ward` → `generalward`)
- Polymorphism (base class pointer to derived object)
- Operator overloading (`cin >>`)
- Dynamic memory allocation (`new` / `delete`)

## How to Run
1. Clone the repo
2. Compile with g++ (e.g. `g++ main.cpp -o hospital`)
3. Run the executable

## Note
Built as a learning project to practice OOP fundamentals in C++.
